# ÉLORA — PROJECT BRIEF

## 1. Brand Identity

Name: ÉLORA
Industry: Premium Fashion & Lifestyle E-commerce
Positioning: Modern, elegant, premium and accessible luxury.

## 2. Visual Direction

- Premium Apple-inspired design.
- Minimalist and elegant interface.
- Refined typography.
- Generous whitespace.
- High-quality product photography.
- Smooth transitions and micro-interactions.
- Consistent design system.

## 3. Color Direction

- Primary: Warm ivory.
- Secondary: Charcoal black.
- Accent: Champagne beige.
- Neutral: Soft gray and white.

Use CSS variables for all design tokens.

## 4. Technology

- HTML5
- CSS3
- Vanilla JavaScript ES6+
- No frontend framework.
- No backend.
- No unnecessary dependencies.

## 5. Pages

1. index.html — Homepage
2. shop.html — Product catalog
3. product-details.html — Product details
4. cart.html — Shopping cart
5. checkout.html — Checkout interface
6. wishlist.html — Favorites
7. about.html — Brand story
8. contact.html — Contact
9. faq.html — Frequently asked questions
10. 404.html — Error page

## 6. Core Features

- Responsive navigation.
- Product search.
- Product categories.
- Product filters and sorting.
- Product detail interactions.
- Shopping cart using localStorage.
- Wishlist using localStorage.
- Quantity management.
- Checkout interface with form validation.
- Newsletter interface.
- Toast notifications.
- Mobile navigation.
- Accessible interactive elements.

## 7. Product Experience

Each product should include:
- Name
- Price
- Description
- Category
- Images
- Available sizes where relevant
- Product availability
- Favorite action

Use realistic demonstration products and clearly identify demo-only functionality.

## 8. Quality Requirements

- Responsive on mobile, tablet and desktop.
- Semantic HTML.
- Accessible controls and forms.
- SEO metadata.
- Optimized assets.
- No broken links.
- No JavaScript console errors.
- No fake interactive elements.

## 9. Implementation Rules

- Respect the existing repository architecture.
- Reuse the existing CSS and JS files.
- Keep code modular.
- Never place the entire application in one HTML file.
- Do not delete or rename existing files.
- Implement one phase at a time.
- Wait for approval before moving to the next phase.

## 10. Final Objective

Deliver a polished, professional, commercially presentable e-commerce template that can be customized and sold as a reusable website template.
